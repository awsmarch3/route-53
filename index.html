🌍 Root DNS Servers

  • 13 root server clusters worldwide
  • Named a.root-servers.net to m.root-servers.net
  • Store TLD nameserver information
  • Operated by various organizations
  • Handle millions of queries per second

🏢 TLD Servers (.com)

  • Managed by Verisign for .com domains
  • Store authoritative nameserver info
  • Distributed globally for performance
  • Handle domain registration data
  • Redirect to domain's nameservers

🎯 Authoritative Servers

  • Amazon's own DNS servers
  • ns1.p31.dynect.net, ns2.p31.dynect.net
  • Store actual DNS records
  • Provide final IP addresses
  • Managed by domain owner

🔄 Recursive Resolvers

  • Your ISP's DNS or public DNS
  • Google (8.8.8.8), Cloudflare (1.1.1.1)
  • Cache responses for performance
  • Query other servers on your behalf
  • Handle the entire resolution process

📋 DNS Record Types Stored in Authoritative Servers
