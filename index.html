⏱️ Typical Resolution Times

Cache Hit
1-5 milliseconds
When DNS record is cached
Full Resolution
20-100 milliseconds
First time lookup
Slow DNS
500-2000 milliseconds
Network issues or overload
Timeout
5-30 seconds
DNS server unreachable

💾 DNS Caching Hierarchy

Browser Cache
Duration: 1-30 minutes
Scope: Single browser session
Purpose: Fastest access for repeated visits
OS Cache
Duration: System dependent
Scope: All applications on device
Purpose: Shared across all programs
Router Cache
Duration: Few hours
Scope: Local network devices
Purpose: Reduces external queries
ISP/Public DNS Cache
Duration: Based on TTL (hours to days)
Scope: Thousands of users
Purpose: Massive performance improvement

🔧 Common DNS Issues & Solutions

DNS Server Not Responding
Solutions:
• Change to public DNS (8.8.8.8)
• Restart router/modem
• Flush DNS cache
Website Won't Load
Check:
• Try different DNS server
• Clear browser cache
• Check if domain expired
Slow DNS Resolution
Optimize:
• Use faster DNS (1.1.1.1)
• Check network connection
• Update router firmware
DNS Cache Issues
Commands:
• Windows: ipconfig /flushdns
• Mac: sudo dscacheutil -flushcache
• Linux: systemd-resolve --flush-caches

📋 DNS Record Types (Stored in Authoritative Servers)

A Record
Maps domain to IPv4 address
www.amazon.com → 54.239.28.85
AAAA Record
Maps domain to IPv6 address
www.amazon.com → 2600:9000:...
CNAME Record
Creates alias for another domain
www → amazon.com
MX Record
Specifies mail servers
amazon.com → mail.amazon.com
NS Record
Lists authoritative nameservers
amazon.com → ns1.p31.dynect.net
TXT Record
Stores text information
SPF, DKIM, domain verification
SOA Record
Start of Authority information
Domain admin, refresh intervals
PTR Record
Reverse DNS lookup
54.239.28.85 → www.amazon.com
